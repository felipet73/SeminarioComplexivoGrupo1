## Datos en producción

| Dato | Dónde vive |
|---|---|
| Índice del RAG (fragmentos y vectores) | Base o almacenamiento externo |
| Documentos originales del caso | Dentro de la imagen (solo lectura) |
| Configuración (config/, prompts) | Dentro de la imagen (solo lectura) |
| Historial de conversaciones | Se pierde al reiniciar (lo aceptamos) |
| Lo que registra el agente (tickets, consultas, reclamos) | Base o almacenamiento externo |
| Archivos que sube el usuario | Base o almacenamiento externo |
| Registros de llamadas al modelo | Base o almacenamiento externo |

**Lo que aceptamos perder y por qué:** Aceptamos perder el historial de conversación al reiniciar, porque solo se utiliza durante la sesión y el usuario puede iniciar otra consulta. Los documentos subidos, el índice actualizado, los borradores confirmados y la auditoría deben conservarse mediante almacenamiento externo, cuya implementación está pendiente.
